# Débito automático

El débito automático es un servicio que permite que el monto del recibo se
cargue automáticamente a la cuenta bancaria o tarjeta del cliente en la
fecha de vencimiento, sin que el cliente tenga que hacer el pago
manualmente cada mes.

## Cómo afiliarse

1. El cliente solicita la afiliación indicando el banco y el tipo de
   cuenta o tarjeta (cuenta de ahorros, cuenta corriente, o tarjeta de
   crédito/débito) desde donde se hará el cargo.
2. Se valida que la cuenta o tarjeta pertenezca al cliente titular del
   servicio (o a un tercero autorizado).
3. Se registra un monto máximo autorizado para el cargo automático — un
   límite de seguridad para que, si un recibo excede ese monto, el sistema
   no cargue automáticamente y el cliente deba pagar ese mes por otro
   medio.
4. Una vez activa la afiliación, cada mes el banco carga automáticamente el
   monto del recibo a la cuenta o tarjeta registrada, en la fecha de
   vencimiento o poco antes.

## Canales para afiliarse

- Banca móvil o banca por internet del banco del cliente, en la sección de
  afiliación a débito automático o "pago de servicios recurrentes".
- Atención presencial en agencia del banco.
- Solicitud directa a través de la operadora, que gestiona la afiliación
  con el banco del cliente.

## Ventajas

- El cliente no corre riesgo de olvidar la fecha de pago ni de acumular
  deuda por descuido.
- No es necesario ingresar a ningún canal cada mes para pagar.

## Consideraciones importantes

- Si la cuenta o tarjeta no tiene fondos suficientes el día del cargo, el
  débito automático falla y el recibo queda pendiente como si no se
  hubiera afiliado ese mes — el cliente debe pagarlo por otro medio para
  evitar la suspensión o corte del servicio.
- Si el monto del recibo supera el monto máximo autorizado, el sistema no
  ejecuta el cargo automático por seguridad.
- El cliente puede desafiliarse en cualquier momento desde los mismos
  canales usados para afiliarse.
